GitHub Actions gratuito open source

Code review de pull request,
publicado pelo seu próprio GitHub Actions.

A cada PR, o AurumCode roda um code review completo: analisa segredo, SQL e command injection sem configurar nada, resume a mudança e comenta na linha certa. Gratuito e open source — o workflow roda dentro da sua própria conta, com seu modelo.

DO REPOSITÓRIO AO PRIMEIRO PARECER

Três passos, nenhum servidor para manter

  1. 1

    Adicione o workflow

    Cole o YAML da seção Instalar em .github/workflows/aurumcode.yml, na branch base do repositório.

  2. 2

    Configure os secrets

    Em Settings → Secrets and variables → Actions, adicione LLM_API_KEY e LLM_BASE_URL do seu endpoint compatível com OpenAI.

  3. 3

    Abra um pull request

    O job roda a cada novo commit do PR e publica comentário, resumo e diagrama na aba Conversation.

O QUE JÁ ESTÁ NO BINÁRIO

Oito capacidades, zero serviço adicional

Sugestão de 1 clique

Comentários ancorados na linha alterada (--na-linha). Quando o GitHub reconhece a substituição, oferece aplicar — o autor decide.

Resumo e diagrama

Todo PR recebe um TL;DR e um fluxograma Mermaid do que mudou, gerado a partir do próprio diff, sem configurar nada.

Análise determinística

Segredo, SQL e command injection são checados em toda revisão. --seguranca soma XSS e o catálogo completo de 8 regras.

Contexto de codebase

O parecer aponta o que mais a mudança pode afetar no repositório, além do diff isolado — por heurística, não por índice completo.

Memória por repositório

Notas de revisão persistem entre execuções (review.memory: local). Observação para o próximo round — nunca aprovação automática.

Fix por CLI

aurumcode fix converte as sugestões publicadas em um patch aplicável, sem depender da interface do GitHub.

Custo sob controle

--limite estima o gasto antes de chamar o modelo e recusa a chamada acima do teto — sem gastar nada nesse caso.

Modelo agnóstico

Qualquer endpoint compatível com OpenAI. Configure LLM_BASE_URL, LLM_API_KEY e, se precisar, LLM_MODEL.

LIMITES

Escopo objetivo

Review do diff do PR. Com provedor, análise semântica; sem provedor, somente baseline offline. review.memory: local exige cache entre jobs; cada execução reavalia o PR inteiro.

COMO USAR CADA RECURSO

Tutoriais de um minuto

Cada capacidade abaixo tem o comando ou o YAML exato. As que rodam sozinhas não pedem nada para funcionar — a configuração só personaliza.

Análise determinística automática

Segredo, SQL e command injection são checados em todo review. Para somar o catálogo completo (XSS + 8 regras):

uses: Mpaape/AurumCode/.github/workflows/review.yml@v2
with:
  security: true

Resumo + diagrama automático

Todo PR ganha um TL;DR e um fluxograma Mermaid do diff. Nada a configurar; o diagrama abre recolhido no comentário.

Contexto de codebase automático

O parecer aponta o que mais a mudança afeta no repositório, por heurística limitada. Sem índice, sem configuração.

Sugestão de 1 clique

Ancore os achados na linha alterada. No review formal, o GitHub oferece aplicar a substituição:

uses: Mpaape/AurumCode/.github/workflows/review.yml@v2
with:
  inline_comments: true

Memória por repositório

Notas persistem entre execuções. Opcional, desligado por padrão:

# .aurumcode/config.yml
review:
  memory: local

Fix por CLI

Converta as sugestões publicadas em um patch aplicável:

docker run --rm aurumcode:local fix < review-response.json > fix.patch
git apply --check fix.patch

Custo sob controle

Estima antes de chamar o modelo e recusa acima do teto, sem gastar:

docker run --rm aurumcode:local review --base HEAD~1 --limite 0.50

Modelo agnóstico

Qualquer endpoint compatível com OpenAI, inclusive local:

export LLM_BASE_URL=http://127.0.0.1:8080/v1
export LLM_API_KEY=your-api-key
export LLM_MODEL=your-model

DO ZERO AO PRIMEIRO REVIEW

Cole um arquivo, adicione dois secrets

Nenhuma conta nova, nenhum serviço para assinar: o workflow abaixo roda no runner do próprio GitHub, com o binário publicado nesta tag.

.github/workflows/aurumcode.yml
name: Code review
on:
  pull_request:
    types: [opened, synchronize, reopened]
permissions:
  contents: read
  pull-requests: write
  statuses: write
  checks: read
jobs:
  review:
    uses: Mpaape/AurumCode/.github/workflows/review.yml@v2
    with:
      model: ${{ vars.LLM_MODEL }}
    secrets:
      LLM_API_KEY: ${{ secrets.LLM_API_KEY }}
      LLM_BASE_URL: ${{ secrets.LLM_BASE_URL }}

Em Settings → Secrets and variables → Actions, adicione LLM_API_KEY e LLM_BASE_URL do seu endpoint compatível com OpenAI; LLM_MODEL é opcional, use se o serviço exigir um nome de modelo. Secrets do repositório não ficam disponíveis em PRs de fork por padrão — não execute código de fork com eles.
