# Arquivo histórico da reconstrução

As especificações AUR-* registram decisões, contratos e evidências do board em
momentos anteriores. Algumas descrevem componentes removidos ou interfaces que
mudaram. Permanecem neste caminho porque a validação e os registros históricos
os referenciam.

Para instalar ou configurar o produto atual, use o [guia de uso](../README.md).
O status de capacidades atuais vem do código e de seus testes; não infira
funcionalidades pela presença de uma especificação.
