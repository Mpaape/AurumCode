# AUR-574: generic text files are reviewed, never dropped by a documentation grammar

## Measurement (before the fix)

Ran the real binary (`review --base HEAD~1`) over `tests/fixtures/repos/git-demo`
with `AURUMCODE_PROMPT_CAPTURE`, inside the shared Go container. The runtime
detects `NOTES.txt` and `config/demo-tokens.txt` as grammar `vimdoc` (chosen
only because of the generic `.txt` extension) and the catalog files `vimdoc`
under `documentation`. Captured prompt:

```
- vimdoc: 2 files
## Code Changes

## Review Coverage
- Code files in this diff: 0
- Code files fully reviewed (every hunk included): 0
- Documentation files excluded from the code rule catalog (...): 2
  - NOTES.txt
  - config/demo-tokens.txt
```

The model never saw the hard-coded token that only the deterministic pass
reports: a confidently wrong answer.
