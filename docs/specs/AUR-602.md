# AUR-602 — Changelog ausente vem com a entrada sugerida

## Medido

- `aurumcode changelog` (AUR-509) só reprovava: a PR sem entrada recebia
  `changelog: reprovado (entrada_ausente): ...` e exit 1, sem nenhuma ajuda
  para escrever a entrada.
- Na PR #108 o job "Changelog obrigatório" falhou com
  `scripts/ci/changelog-check.sh: No such file or directory`: no próprio
  repositório o verificador é construído da **base** da PR (segurança), e a
  base ainda não tinha o verificador (primeira introdução).
- `.github/workflows/changelog.yml` pinava `actions/checkout` em v4.2.2; o
  `docs.yml` já usa o SHA da v7.0.1.

## O que mudou

| arquivo | responsabilidade |
|---|---|
| `internal/changelog/suggest.go` | `Suggestion`; `SuggestFromCommits` (só assuntos; descarta merges, `fixup!`/`squash!`, marcadores de log de agente, linhas abaixo de `min_words`; escapa, corta em `max_line_length`, limita a `max_entry_lines`); `SuggestFromModel` (exige `{"entry": [...]}` e aplica as mesmas regras). |
| `internal/changelog/suggest_prompt.go` | Pedido ao modelo: só caminhos alterados e assuntos de commit, limitados, marcados como dado. |
| `internal/changelog/render.go` | `Suggestion.Block()`: `## <section>` e os bullets, prontos para colar. |
| `cmd/aurumcode/changelog_suggestion.go` | Fontes do check (`changelogDeps`: diff, commits `base..head`, provedor como no review); `offerSuggestion` só quando o veredito é reprovação não indeterminada; redação única (`redactSuggestion`); log, `$GITHUB_STEP_SUMMARY` e bloco Markdown traduzido. |
| `cmd/aurumcode/cmd_changelog.go` | `runChangelogWith`; a reprovação continua `exitChangelogRefused` (1) com ou sem sugestão. |
| `cmd/aurumcode/changelog_sides.go` | `evaluateChangelog` devolve a regra efetiva (nil = não exigido). |
| `cmd/aurumcode/pr_changelog_suggestion.go` | `review --pr`: com `changelog_check` exigido e o arquivo ausente do diff (e não ignorado pelo review), o parecer ganha o bloco, da fonte `commits` (sem chamada extra ao modelo). |
| `internal/i18n/catalog.yml` | `changelog.suggestion.heading` e `changelog.suggestion.intro` em pt-BR e en. |
| `.github/workflows/changelog.yml` | Checkouts no SHA da v7.0.1; base sem `scripts/ci/changelog-check.sh` no próprio repositório imprime `::notice::` de primeira introdução e sai 0 (no consumidor continua erro); `GITHUB_STEP_SUMMARY` montado no container. |
| `scripts/ci/changelog-check.sh` | Comentário: o comando grava a sugestão no resumo do job. |
| `docs/configuration.md`, `docs/tutorials/changelog.md`, `demo/tutoriais/changelog` | Seção "Entrada sugerida"; caso 6 `sugestao-da-entrada` com `fixture-sugestao.json`; linha nova em `tests/fixtures/tutorials/mapa.tsv`. |

Limite declarado: o container do workflow não recebe credencial de provedor,
então no CI a sugestão vem sempre dos commits; a fonte `modelo` é provada por
fixture.
