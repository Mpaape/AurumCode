## What changed

- `internal/gate/facts` (facts.go): `AuditFinding`, `AuditException`,
  `AnalysisDataAudit` (same fields and JSON tags). `internal/render` keeps
  them as type aliases, so its API and the serialized audit are unchanged;
  `internal/gate` uses `facts.*` and no longer imports `render`. (A first
  version put them in `pkg/types`; moved because `pkg` is outside the
  card's paths.)
- `config.(*Config).PolicyDigest(policyDir)` (internal/config/policydigest.go)
  holds the digest, nil-safe; `render.PolicyDigest(policyDir, PolicySource)`
  takes any value with that method (a typed or untyped nil gives ""), so
  `render` no longer imports `config` and callers are unchanged.
- The Dependency-Track threshold conversion moved to `internal/gate/dtrack.go`
  (`clientThresholds`); `config` keeps only `dtrack.ValidateHost`, declared as
  a symbol exception in the layer table.
- `internal/config/governance.go`: `governedSections` (key, rule) in warning
  order, `reviewPolicyFields`/`reviewRepositoryFields`,
  `qualityGateSections`. `ApplyCentralPolicy` walks the table (14 lines; `GenerateReviewWithContext` is 21).
  `governance_test.go` reflects over `Config`, `ReviewConfig` and
  `QualityGatesConfig` and fails for an unclassified field, a classification
  of a field that does not exist, or a double classification.
- `gate.Contributor.Apply(ctx, run, prior Result) (Result, error)`: each
  contributor returns its partial decision and `Pipeline.Run` merges it
  (`Result.Merge`, which now also carries an `AnalysisData` fact).
  `MergeDTrackGate` removed. The policy-skills partial clears its reason (the
  run's reason is already in the result), so no reason is joined twice.
- `tokens.Estimate` (internal/llm/tokens) is the one heuristic; `prompt.HeuristicEstimator`,
  `llm.heuristicTokens` (never below 1, as before) and
  `skills.EstimateTokens` delegate to it.
- Skill front matter is decoded with `gopkg.in/yaml.v3` (already a
  dependency): a list, a block list or a comma-separated scalar; unknown keys
  ignored; malformed YAML is an error naming the file (fail closed; it used
  to be read leniently).
- `renderSlot` never panics: a failed slot renders a NUL-delimited failure
  mark; `BuildPrompt` and `FixedOverheadTokens` refuse a prompt that carries
  one, with the slot name and cause. Signatures (and the anchors finished
  acceptance scripts edit) are unchanged.
- `docs/architecture.md`: new "Layers" table (the test's source), the
  configuration-section and contributor extension points, the guard list.
- `cmd/aurumcode/structure_test.go`: `TestImportsFollowLayerTable` (reads the
  table; a file exception or symbol exception that matches nothing fails),
  `TestNoFunctionExceedsLineLimitAnywhere` and
  `TestNoProductionFileNamedByCardAnywhere` over cmd, internal and pkg,
  `TestReviewSourcesReturnNoGateExitCode` (named constants, any `gate.Exit*`
  selector, the literal value of `gate.ExitFindings`; literals 1 and 2 stay
  legal because each early exit keeps its own code),
  `TestNoEngineBranchInGateOrCmdByAnyName` (literal, named constant, map key,
  index).
