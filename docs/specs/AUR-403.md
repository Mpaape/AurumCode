# AUR-403 — Perfil Go unit offline

`go-unit-offline-v1` usa o schema dedicado
`.board/schemas/go-unit-offline-profile.schema.json`, é registrado no
registry canônico em ordem lexicográfica e fixa seu lock content-addressed.
O lock usa uma imagem Go por digest; tags mutáveis são rejeitadas antes de
qualquer engine.

O profile mantém rede none, rootfs e checkout read-only, usuário não-root,
capabilities removidas, limites bounded, cache `/go/pkg/mod` somente leitura,
`GOPROXY=off`, `GOSUMDB=off`, `GONOSUMDB=*`, `GOTOOLCHAIN=local` e somente
o array exato `["go", "test", "-mod=readonly", "./..."]`. O loader confirma a
coerência das invariantes do schema, exige o conjunto completo de chaves do
profile e do ambiente e rejeita chaves desconhecidas, duplicadas ou bytes após
o documento. Fixtures hostis cobrem a omissão de `privileged` e a tentativa de
representar o comando permitido com apenas três elementos.

A aceitação executa unit, contract, integration, E2E e o `AC-001` completo do
AUR-402, incluindo suas quatro camadas e mutações. Os vetores rejeitam
duplicidade, lock com tag mutable e alteração de
isolamento (`network`, mounts, devices, rootfs ou capabilities), sempre antes
de qualquer invocação de engine.
