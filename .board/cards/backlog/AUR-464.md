## Outcome

Quem abre uma pagina gerada consegue responder o que aquele simbolo faz, o que recebe e o que devolve, sem abrir o codigo.

## Achado medido (2026-08-14)

Pagina real gerada por esta ferramenta, em
`.aurumcode/bash/run-docs-pipeline.sh.md`:

    # run-docs-pipeline.sh
    ## Documentation
    Run AurumCode Documentation Pipeline in Docker
    ## Documentation
    Check if .env exists
    ## Documentation
    Load environment variables
    ## Documentation
    Build and run

`## Documentation` repetido como cabeçalho de cada bloco de comentario, sem
nome de simbolo, sem assinatura, sem parametro, sem retorno. A origem e
literal: `extractors/bash/extractor.go:127` e
`extractors/powershell/extractor.go:131,148` escrevem `"## Documentation\n\n"`
para cada bloco encontrado.

Um sumario navegavel construido sobre isso tem N entradas identicas chamadas
"Documentation", entao a navegacao tambem nao funciona.

## Non-goals

- Nao redesenhar o tema Jekyll nem trocar `just-the-docs`. O defeito esta no
  markdown gerado, nao no CSS.
- Nao gerar prosa que o codigo nao tem. Sem comentario, a pagina mostra a
  assinatura e o silencio -- que e informacao honesta.
- Nao mudar a saida dos extratores nativos de Go, Rust e C# que ja nomeiam
  simbolo, a menos que eles tambem repitam cabecalho.
