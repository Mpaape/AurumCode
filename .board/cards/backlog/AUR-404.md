## Outcome

o profile go-git-offline-v1 fixa Go e Git por digest, materializa apenas fixture Git descartável e proíbe checkout host, credentials, hooks, signing helpers e rede.

## Non-goals

- Criar a fixture Git descartável ou caracterizar qualquer repositório real; `go-git-offline-v1.json` só fixa Go e Git por digest e nega checkout host, hooks, credential helpers e rede.
- Agregar outro profile ou aceitar fallback para profile, lock ou imagem não registrados.

## Preconditions

- O schema de AUR-006 está aprovado e os inputs do registry são dados não confiáveis.
- O acceptance está selado e nenhuma credential ou valor de ambiente integra as fixtures.

## Postconditions

- o profile go-git-offline-v1 fixa Go e Git por digest, materializa apenas fixture Git descartável e proíbe checkout host, credentials, hooks, signing helpers e rede.
- Nenhum engine é invocado para profile inválido e nenhum byte fora de `paths` muda.
