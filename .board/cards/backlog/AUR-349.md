## Outcome

O fake Anthropic retorna um único content block `tool_use` strict e
determinístico, sem executar a tool ou vazar tipos para o domínio.

## Non-goals

- tool_result, streaming tool delta, OpenAI tool shape ou execução local/remota.
- Aceitar tool name/schema fora da allowlist.

## Preconditions

- AUR-055/AUR-057/AUR-350 aprovados e version header válido conforme AUR-343.
- Tool runtime e credentials não existem no profile.

## Postconditions

- Nominal retorna stop_reason `tool_use` e exatamente um block com input object golden.
- Invalid name/schema/input falha antes de montar response parcial.

## Acceptance scenarios

### AC-001: Emitir Anthropic tool_use block

- Given: `tests/specs/AUR-349/cases.yaml` define tool `read_symbol`, strict input schema, object `{"symbol":"ReviewResult"}`, unknown name, schema permissivo e input >8 KiB.
- When: o client chama Messages e registra definition digest, stop reason, block type/id/name/input digest, error e execution count.
- Then: nominal retorna um `tool_use` block e usage golden; inválidos retornam `tool_not_allowed`, `tool_schema_not_strict` e `tool_input_too_large` sem block.
- And: nenhuma estrutura OpenAI aparece, `tool_executions=0` e replay preserva block ID/digest.

- Covers requirements: [PR-ARCH-001, PR-LLM-001]
- Covers controls: [CR-EVD-001, CR-EVD-002, CR-EVD-003, CR-REV-001, CR-REV-002, CR-REV-003, CR-REV-004, CR-REV-005, CR-GATE-001, CR-TRUST-002, CR-TRUST-004]
