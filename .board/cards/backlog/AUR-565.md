## Outcome

O tutorial do AUR-561 provou que a selecao de skills por linguagem
(`.aurumcode/skills/<dir>/SKILL.md` com `languages:`), os apelidos do
catalogo (AUR-559) e o aviso de apelido desconhecido existem so como
biblioteca (`internal/context/skills`): o `review` nao le esse formato; o
que funciona na CLI e `.aurumcode/instructions/*.md` com `applyTo`. Com
este card, o review (`--base` e `--pr`) resolve as skills do repositorio e
da politica pelo provider de skills: selecao por linguagem via gramatica,
apelidos pelo catalogo, apelido desconhecido declarado no contexto enviado
ao modelo e no parecer, e skill referenciada ausente tratada como hoje
(aviso no repo; erro de carga na politica). `instructions/*.md` continua
funcionando. O tutorial `docs/tutorials/skills.md` e a demo sao atualizados
para o comportamento real, com o caso de selecao por linguagem passando a
chegar ao prompt.

## Non-goals

Mudar o formato de skill alem de `languages:`; novas gramaticas.

## Acceptance scenarios

- AC-001: Skill com `languages: [typescript]` entra no prompt para um diff .ts e nao para um diff .go (prova no contexto enviado ao modelo via fixture).
- AC-002: Apelido `ts` resolve; apelido desconhecido aparece como aviso no contexto e no parecer, nunca em silencio.
- AC-003: Skill da politica com o mesmo seletor vence a do repositorio, com aviso.
- AC-004: O tutorial de skills regravado (`out/`) mostra o caso de selecao por linguagem chegando ao prompt; `--check` passa.

## Skeptical mutations

- MUT-001: Ignorar `languages:` e enviar toda skill reprova AC-001.
