## Outcome

o profile fake-provider-v1 executa adapter OpenAI-format contra fake local determinístico, sem API key real, DNS ou egress, com scripts de resposta, timeout e output bounds pinados.

## Non-goals

- Implementar o fake OpenAI-format, escrever os scripts de resposta ou exercitar o adapter de LLM; `fake-provider-v1.json` apenas pina endpoint local, timeout, output bounds e ausência de API key real.
- Agregar outro profile ou aceitar fallback para profile, lock ou imagem não registrados.

- As invariantes de segurança de AUR-006 e o registry extensível entregue por AUR-403 estão aprovados; os inputs do registry continuam dados não confiáveis.

## Postconditions
