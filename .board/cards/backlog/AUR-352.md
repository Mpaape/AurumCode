## Outcome

Um manifesto liga cada `.aurumcode/bash/*.md` ao script-fonte alegado, hash,
ownership e disposição, com `executed=false` e sem avaliar blocos shell.

## Non-goals

- Executar, regenerar ou corrigir scripts/docs; AUR-312 decide os scripts raiz.
- Declarar que texto gerado é atual sem prova de source digest.

## Preconditions

- AUR-001 sela a árvore, AUR-009 define canários e AUR-312 caracteriza scripts-fonte.
- Parser Markdown lexical nega subprocess, link fetch e shell evaluation.

## Postconditions

- Cada doc possui source relation ou `orphan`, disposição e `executed=false`.
- Docs e scripts permanecem intactos, com zero processo/rede.

## Acceptance scenarios

### AC-001: Mapear bash docs sem rodar snippets

- Given: árvore hash-lockada e fixtures com orphan, stale digest e fenced command hostil.
- When: parser extrai apenas metadata/source references.
- Then: todos os docs aparecem com relation/disposition e execution flag false.
- And: replay/source hashes coincidem e process audit é vazio.

- Covers requirements: [PR-ARCH-001, PR-DOC-003, PR-SEC-001]
- Covers controls: [CR-EVD-001, CR-EVD-002, CR-EVD-003, CR-REV-001, CR-REV-002, CR-REV-003, CR-REV-004, CR-REV-005, CR-GATE-001, CR-TRUST-001, CR-TRUST-004, CR-TRUST-005]
