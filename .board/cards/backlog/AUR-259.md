## Outcome

aurumcode resume continua um run interrompido a partir do CAS exato sem repetir stage concluído.

## Non-goals

- Reexecutar stages já concluídos para revalidá-los ou reconstruir o run do zero quando o CAS estiver ausente.
- Publicação e credenciais, salvo quando explicitamente nomeadas no outcome.

- os manifests aprovados de AUR-150, AUR-151, AUR-152 estão disponíveis na mesma base.

## Postconditions

## Acceptance scenarios

### AC-001: Expor resume de run na CLI

- Given: manifests aprovados de AUR-150, AUR-151 e AUR-152 na mesma base, um run interrompido com dois stages já persistidos no CAS e o perfil `sqlite-offline-v1` ativo.
- When: `aurumcode resume` é invocado uma vez sobre o run interrompido, carregando a versão CAS corrente do último stage concluído.
- Then: o stage já concluído não gera novo evento no CAS e `.board/evidence/AUR-259/acceptance/AC-001.json` registra a retomada a partir da versão exata, com exit code 0.
