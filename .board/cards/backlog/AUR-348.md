## Outcome

O fake Responses devolve um output item `function_call` canônico para uma tool
estrita, sem converter para Chat tool_calls nem executar a função.

## Non-goals

- Chat tool_calls, streaming function deltas, function_call_output ou execução.
- Downgrade de tool choice/schema incompatível.

## Preconditions

- AUR-055/AUR-057/AUR-350 aprovados e schema fixture content-addressed.
- Nenhuma capability de tool runtime está montada no container.

## Postconditions

- Nominal retorna um output item function_call com call_id/name/arguments golden.
- Tool choice ou schema incompatível falha antes de gerar output.

## Acceptance scenarios

### AC-001: Emitir Responses function_call

- Given: `tests/specs/AUR-348/cases.yaml` fixa function `find_entity`, strict object schema e args `{"name":"CandidateIdentityV1"}`, mais choice desconhecida, schema non-strict e args >8 KiB.
- When: o Responses client envia o request e captura schema digest, output-item type/count, call fields digest, error code e execution count.
- Then: nominal retorna status completed e um item `function_call`; inválidos retornam `tool_choice_not_allowed`, `tool_schema_not_strict` e `tool_arguments_too_large` sem output parcial.
- And: o wire nunca contém Chat `tool_calls`, `function_executions=0` e replay preserva call_id/digest.

- Covers requirements: [PR-ARCH-001, PR-LLM-001, PR-LLM-002]
- Covers controls: [CR-EVD-001, CR-EVD-002, CR-EVD-003, CR-REV-001, CR-REV-002, CR-REV-003, CR-REV-004, CR-REV-005, CR-GATE-001, CR-TRUST-002, CR-TRUST-004]

## Security and privacy

- Data flow: schema/args sintéticos -> loopback -> digests/counts.
- Secrets: canário em args causa rejeição e não é logado.
- Least privilege: sem tool executor, shell, egress, host mount ou socket.
