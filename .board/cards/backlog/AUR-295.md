## Outcome

um entry adapter Cloud Functions chama o mesmo composition root e contrato HTTP sem credencial embutida.

## Non-goals

- Triggers Pub/Sub, Storage ou Eventarc e deploy real da function; o escopo é o entry HTTP e sua fiação local.
- Autoridade ou efeito externo não nomeado no outcome.

## Preconditions

- os manifests aprovados de AUR-226 estão disponíveis na mesma base.
- Acceptance selado, árvore limpa e CandidateIdentityV1 completa.

## Postconditions

- um entry adapter Cloud Functions chama o mesmo composition root e contrato HTTP sem credencial embutida.
- Fora de `paths`, bytes, estado e capabilities permanecem iguais.

## Acceptance scenarios

### AC-001: Empacotar adapter Cloud Functions

- Given: `deploy/gcp/cloud-functions` contém o entry adapter da function e o profile `release-build-v1` expõe o mesmo composition root usado pelos demais entrypoints.
- When: `tests/e2e/deploy/cloud-functions` invoca a function localmente com um evento HTTP válido e inspeciona a árvore de inicialização.
- Then: a function delega ao composition root compartilhado, responde o mesmo contrato HTTP e nenhuma credencial literal existe nos fontes de `deploy/gcp/cloud-functions`.
- And: replay da identidade exata é estruturalmente idêntico.
