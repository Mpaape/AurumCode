## Outcome

um analyzer job read-only da Action executa docs e publica apenas o bundle para o publisher separado, sem ampliar o contrato CLI.

## Non-goals

- Publicar o bundle em pages, branch ou release e conceder token de escrita: a publicação fica no job separado, atrás de outra fronteira de confiança.
- Publicação e credenciais, salvo quando explicitamente nomeadas no outcome.

## Acceptance scenarios

### AC-001: Expor docs na GitHub Action

- Given: os manifests de AUR-108 e AUR-124 fixam o comando docs e o formato do bundle, e o workflow de `deployments/github-action/docs` recebe um checkout de pull request não confiável com token de escrita indisponível para o job analyzer.
- When: o workflow de `deployments/github-action/docs` executa o job analyzer sobre o checkout não confiável e encerra entregando o bundle ao job publisher.
- Then: o job analyzer roda com token read-only, grava apenas o bundle de docs como artifact para o publisher, e o contrato de flags do CLI permanece byte a byte igual ao do base.
- And: replay da mesma CandidateIdentityV1 é estruturalmente idêntico.
