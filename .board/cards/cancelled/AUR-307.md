## Compatibility, migration, rollback

- Compatibility: todo contrato fora deste card é preservado.
- Migration: not-applicable salvo quando o outcome nomeia legado; nesses casos a caracterização é precondição e o artifact registra before/after.
- Rollback: reverter só `paths`, restaurar artifact caracterizado quando aplicável e repetir AC-001 sem efeito externo novo.

## Review

- Reviewer: one independent reviewer reads the exact immutable candidate in a clean detached worktree and checks every changed hunk, the public contract, paths/read_paths, acceptance, declared selectors, mutations, profile/runtime compatibility, security boundaries, and exit-code handling.
- Independence: the reviewer is separate from the builder and does not edit the candidate or write evidence in the coordinator checkout. No extra review role is required.
- Verdict: approve only on raw exit 0 with real assertions. Runtime, loader, image, dependency, or other infrastructure failures are blocked or inconclusive, never approval. The validator reruns the declared acceptance on the same SHA when validation is not none.

## Evidence

Only the coordinator writes sanitized evidence under .board/evidence/<card-id>/; tests and builders emit observations only. Evidence binds the exact candidate SHA, review verdict, acceptance/validation exits, mutation result when declared, clean tree, and artifact hashes. Never store secrets, raw prompts/responses, credentials, environment values, or chain-of-thought.

  carregar. O histórico permanece rastreável em Git; nada foi apagado.

  verificável rodando sob `bootstrap-readonly-v1`, o único profile carregável.
