## Outcome

Uma mudança Rust elegível produz uma proposta unitária estruturada, bounded e vinculada ao change digest; geração não executa o teste nem afirma cobertura, não vacuidade, ausência de flake ou aprovação.

## Non-goals

- Compilar o crate, executar `cargo test` sobre a proposta ou calcular mutation score do teste Rust sugerido.
- Tratar saída do modelo como código confiável, evidência de teste ou autorização de escrita.

## Preconditions

- AUR-131, AUR-132 e o profile fake-provider-v1 estão aprovados para a mesma CandidateIdentityV1.
- Contexto, schema de proposta e fake responses estão pinados e não contêm credenciais.

## Postconditions

- A proposta Rust contém arquivos, patch, comandos sugeridos e rationale bounded, todos ligados ao change digest.
- O resultado é apenas candidato não confiável; nenhum arquivo do consumidor é aplicado ou executado.

- Repository context e model output são dados não confiáveis; somente campos do TestProposalV1 bounded atravessam o adapter.
- API keys reais, env, prompts/respostas brutos e `AURUM_SECRET_CANARY` não entram em fixtures, logs ou evidência.
- O gerador não possui capability de aplicar patch, executar toolchain, publicar ou aprovar.

## Compatibility, migration, rollback

- Compatibility: contratos fora deste card permanecem iguais.
- Migration: not-applicable; mudança de legado/estado usa card dedicado.
- Rollback: reverter apenas `paths`, remover derivados card-scoped e provar o base sem efeito externo.

## Review

- Reviewer: one independent reviewer reads the exact immutable candidate in a clean detached worktree and checks every changed hunk, the public contract, paths/read_paths, acceptance, declared selectors, mutations, profile/runtime compatibility, security boundaries, and exit-code handling.
- Independence: the reviewer is separate from the builder and does not edit the candidate or write evidence in the coordinator checkout. No extra review role is required.
- Verdict: approve only on raw exit 0 with real assertions. Runtime, loader, image, dependency, or other infrastructure failures are blocked or inconclusive, never approval. The validator reruns the declared acceptance on the same SHA when validation is not none.

## Evidence

Only the coordinator writes sanitized evidence under .board/evidence/<card-id>/; tests and builders emit observations only. Evidence binds the exact candidate SHA, review verdict, acceptance/validation exits, mutation result when declared, clean tree, and artifact hashes. Never store secrets, raw prompts/responses, credentials, environment values, or chain-of-thought.

  carregar. O histórico permanece rastreável em Git; nada foi apagado.

  verificável rodando sob `bootstrap-readonly-v1`, o único profile carregável.
