## Outcome

Um manifesto emparelha os cinco `SKILL.md` de `.agents/skills` e
`.claude/skills`, prova igualdade byte a byte, origem/provenance e
`untrusted=true`, sem carregar ou executar instruções durante a comparação.

## Non-goals

- Instalar, atualizar, remover, interpretar ou conceder ferramentas a qualquer skill.
- Escolher novo conteúdo canônico ou alterar o symlink `AGENTS.md -> CLAUDE.md` tratado por AUR-319.

## Preconditions

- AUR-001 sela ambos roots, AUR-009 define sinks, AUR-013 audita escritorio e AUR-068 define skill schema/capabilities.
- Enumeração aceita somente os cinco nomes allowlisted e arquivos regulares bounded.

## Postconditions

- Dez arquivos formam cinco pares completos, cada um com dois hashes iguais, provenance, mode e flags `byte_equivalent=true`, `untrusted=true`.
- Conteúdo, permissões e routing roots permanecem inalterados e nenhuma skill é ativada.

## Acceptance scenarios

### AC-001: Provar mirrors completos sem confiar no conteúdo

- Given: dois roots hash-lockados e fixtures com pair drift, skill extra, symlink e capability hostil.
- When: comparador allowlisted lê bytes como dados e produz uma linha por par.
- Then: os cinco pares aparecem equivalentes/untrusted; drift, ausência, extra ou symlink falha closed.
- And: nenhum texto de skill entra como instrução, prompt de aprovação ou tool request.

- Covers requirements: [PR-ARCH-001, PR-SKL-001]
- Covers controls: [CR-EVD-001, CR-EVD-002, CR-EVD-003, CR-REV-001, CR-REV-002, CR-REV-003, CR-REV-004, CR-REV-005, CR-GATE-001, CR-TRUST-001, CR-TRUST-002, CR-TRUST-004]

## Security and privacy

- Data flow: paths/modes/hashes/provenance -> TSV; body não chega a prompt, executor ou evidence.
- Secrets: scanner bounded trata corpos como dados; canário sintético nunca aparece em sinks.
- Least privilege: read-only, allowlist exata, sem install/refresh/tool/network e sem seguir symlink.

## Documentation

- `docs/specs/AUR-340.md` define pair schema, untrusted semantics e separação do workflow de instalação.

## Compatibility, migration, rollback

- Compatibility: mantém os dois roots necessários aos clientes atuais sem declarar autoridade.
- Migration: eventual source canônico/refresh exige card próprio com rollback dos dois mirrors.
- Rollback: remover apenas manifesto/docs/evidence; dez arquivos permanecem intactos.

## Review

- Reviewer: one independent reviewer reads the exact immutable candidate in a clean detached worktree and checks every changed hunk, the public contract, paths/read_paths, acceptance, declared selectors, mutations, profile/runtime compatibility, security boundaries, and exit-code handling.
- Independence: the reviewer is separate from the builder and does not edit the candidate or write evidence in the coordinator checkout. No extra review role is required.
- Verdict: approve only on raw exit 0 with real assertions. Runtime, loader, image, dependency, or other infrastructure failures are blocked or inconclusive, never approval. The validator reruns the declared acceptance on the same SHA when validation is not none.

## Evidence

Only the coordinator writes sanitized evidence under .board/evidence/<card-id>/; tests and builders emit observations only. Evidence binds the exact candidate SHA, review verdict, acceptance/validation exits, mutation result when declared, clean tree, and artifact hashes. Never store secrets, raw prompts/responses, credentials, environment values, or chain-of-thought.

## Cancellation

- 2026-08-12: cancelado na reorientação do board para entregas executáveis. O
  dono determinou que o AurumCode precisa disparar agentes e fazer code review
  automático, e que cada card deve terminar num comando executável. Este card
  não compõe esse caminho, ou especifica em greenfield um comportamento que o
  código existente já cumpre, ou depende de um profile OCI que o runner recusa
  carregar. O histórico permanece rastreável em Git; nada foi apagado.
- Substituído pela série AUR-500..AUR-515, em que cada card entrega um comando
  verificável rodando sob `bootstrap-readonly-v1`, o único profile carregável.
