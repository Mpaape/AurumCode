## Outcome

Lacuna documentada no AUR-513: `cache.PromptVersion` e uma constante que
alguem precisa lembrar de incrementar quando o prompt embutido muda. Esquecer
serve respostas antigas do cache para um prompt novo. A versao passa a ser um
digest do conteudo fixo que o builder do prompt realmente renderiza
(instrucoes, catalogo embutido, schema), calculado a cada execucao.

## Non-goals

Mudar o prompt; mudar o formato do cache alem da chave.

## Acceptance scenarios

- AC-001: Alterar qualquer texto fixo do prompt embutido muda a chave do cache e forca review novo, sem editar constante.
- AC-002: Sem mudanca no prompt, a chave e estavel entre execucoes.
- AC-003: Mesmo modelo servido por outra base URL (outro endpoint) faz review novo, provado ponta a ponta com dois servidores; hoje nenhum teste guarda isso (pendencia da revisao do AUR-513).

## Skeptical mutations

- MUT-001: Voltar para a constante fixa faz AC-001 falhar.
