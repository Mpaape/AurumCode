## Outcome

Quando o modelo devolve uma resposta que o parser nao valida
(`validation_failed`), a review NAO derruba o comando sem publicar nada: ela
publica os passes deterministicos (analise estatica + seguranca), marca o
modelo como inconclusivo com uma limitacao declarada, e o exit segue o gate
deterministico.

## Achado medido (2026-09-15)

No auto-review do repo (PRs #37/#40, modelos `gpt-4o-mini` e `gpt-4o` num diff
grande), o comando saiu com `could not understand the model's response
(validation_failed)` e exit 1, sem publicar achado deterministico algum. Para um
gate de CI isso e ruido: uma resposta fora do formato derruba a PR inteira.

## Non-goals

Nao trocar o modelo; nao reimplementar o parser; nao aceitar saida malformada
como valida. O caminho `--base` fica com o contrato do AUR-458 (a degradacao foi
escopada ao `--pr`, onde o defeito foi medido).
