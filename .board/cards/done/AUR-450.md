## Outcome

Quando a passagem de seguranca nao acha nada, ela diz sobre QUE regras a busca foi feita, para o usuario nao ler `No security findings.` como se o codigo tivesse sido varrido por completo.



## Achado medido (reteste 2026-08-14)

Codigo com `hashlib.md5(password)` (weak-crypto) e `"<b>" + name + "</b>"`
(xss) recebe `Security findings (standards/security-review): No security
findings.` com exit 0. Cinco das oito regras do catalogo sao metadata-only
e o CLI nunca diz quais — o usuario le silencio como cobertura. Nao e
falso positivo nem falso negativo de um matcher: e a saida omitindo o
proprio alcance. Conserto: a saida da passagem nomeia as regras
efetivamente aplicadas (ou o numero aplicadas/total com ponteiro para a
lista), tanto no caso com achados quanto no caso vazio.
