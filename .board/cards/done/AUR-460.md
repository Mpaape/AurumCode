## Outcome

O usuario escolhe qualquer modelo servido pelo gateway dele. Hoje a temperatura fixa em 0.3 faz familias inteiras de modelo recusarem a chamada com erro 400.




## Achado medido (teste ao vivo com gateway real 2026-08-14)

`--modelo gpt-5.6-luna` contra gateway real: erro 400 do provider —
"Unsupported value: 'temperature' does not support 0.3 with this model.
Only the default (1) value is supported". Toda a familia gpt-5.6 (luna,
sol, terra) e inalcancavel, e o usuario nao tem como configurar. O gateway
oferecia 82 modelos; um subconjunto e simplesmente impossivel de usar.
Conserto minimo: parametro de amostragem configuravel e omitido por padrao
quando o modelo nao o suporta — ou omitido sempre, deixando o default do
provider. Nao inventar tabela de compatibilidade por modelo: preferir
omitir e, se o provider reclamar, reportar com a mensagem dele.
