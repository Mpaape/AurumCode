## Outcome

O tutorial do AUR-563 mediu que `analysis_data` fixa `api.github.com` no
binario: nao ha como apontar para GitHub Enterprise nem para um servidor de
teste sem truque de DNS/CA (o tutorial precisou de um servidor falso HTTPS
atendendo como esse nome). Com este card o endereco da API usado pelo
`analysis_data` vem da mesma fonte que o cliente de PR
(`AURUMCODE_GITHUB_API_URL`, com padrao `https://api.github.com`), e so
aceita `https://` (ou loopback literal para teste); o tutorial troca o
servidor falso HTTPS por um loopback simples e regrava os casos.

## Non-goals

Mudar o formato do artefato; GitHub Enterprise alem do endereco.

## Acceptance scenarios

- AC-001: Com `AURUMCODE_GITHUB_API_URL` apontando para o servidor falso em loopback, o review resolve o artefato de la; sem a variavel, usa o padrao.
- AC-002: Endereco `http://` nao loopback e recusado como erro de carga.
- AC-003: Tutorial regravado sem CA de demonstracao.

## Skeptical mutations
