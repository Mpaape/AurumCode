## Outcome

Um repositorio Noxy gera documentacao sem instalar nada, como Go, Rust, C# e
JavaScript ja geram.

## Gramatica levantada da fonte oficial (2026-08-26)

Linguagem: **Noxy**, criada por `estevaofon`. Site `https://noxylang.com/`,
spec em `docs/NOXY_LANGUAGE_SPEC.md` do repositorio `estevaofon/noxy`.
Extensao de arquivo: **`.nx`**. O compilador e escrito em Go.

Formas que o extrator precisa reconhecer, citadas da spec:

    func add(a: int, b: int) -> int
        return a + b
    end

    func first<T>(arr: T[]) -> T          // generica
        return arr[0]
    end

    let adder: func = func(x: int) -> int  // anonima atribuida
        return x + 1
    end

    struct Point
        x: int
        y: int
    end

    struct Stack<T>                        // generica
        items: T[]
    end

    let name: string = "Noxy"              // com tipo
    let n = 5                              // tipo inferido
    let p: Point?                          // sem inicializador, anulavel

    use noxydb                             // import de modulo

Comentario e SO de linha, `//`; a spec nao documenta bloco. String tem tres
formas: `"..."`, bytes `b"..."`, e f-string `f"Hello, {name}!"` onde cada
`{e}` compila para `to_str(e)`. Ha tambem `fmt("Value: %d", 255)` no estilo
printf.

## Non-goals

- Nao escrever um parser completo de Noxy. O alvo e a superficie documentavel:
  `func` (inclusive generica), `struct` (inclusive generica), `let` de topo, e
  o bloco de comentarios `//` imediatamente acima.
- Nao gerar prosa que o codigo nao tem. Simbolo sem comentario sai com
  assinatura e silencio -- a regra que o AUR-463 e o AUR-464 ja estabeleceram.
- Nao cobrir a passagem de SEGURANCA aqui. Ela e outro card e depende do
  AUR-481 liberar `internal/review/rules`.
- Nao executar o compilador Noxy: extrator nativo, como Rust e C# fizeram no
  AUR-427.

## Achado que o proximo card de seguranca precisa saber

`noxydb`, o banco da linguagem, e CHAVE-VALOR e nao SQL -- a amostra oficial usa
`noxydb.open_database`, `noxydb.put` e `noxydb.get` com `map[string, any]`. Logo
a regra `security/sql-injection` provavelmente NAO se aplica a Noxy, e afirmar
que se aplica seria cobertura falsa. Ja `security/hardcoded-secret` se aplica e
hoje FALHA pela mesma causa do Rust: `let API_KEY: string = "..."` poe um tipo
entre o nome e o `=`, e o pattern espera aspas logo apos `:` ou `=`. Execucao de
comando nao aparece na documentacao levantada; confirmar antes de prometer.
