## Outcome

O profile Go registrado e aceito pelo mesmo contrato que o runner realmente carrega. O coordenador consegue executar uma assercao Go real em OCI, sem toolchain no host e sem profile local substituto.

## Non-goals

Reescrever o escritorio, reabrir evidencias done, relaxar isolamento, criar nova imagem por agente ou implementar features do produto.

## Acceptance scenarios

- AC-001: O loader e o preflight aceitam o profile canonico e rejeitam lock divergente, runtime Bash-only para Go e campo de privilegio nao permitido.
- AC-002: Uma fixture rastreada de teste Go executa uma assercao pelo runner real; mutar o retorno da funcao faz o mesmo comando falhar. Probe que so localiza go nao basta.
- AC-003: Cache offline, scratch executavel e recursos suficientes ficam declarados e medidos; sem rede, mounts de host ou git dentro do container. O helper compartilhado nao executa git no container.
- AC-004: O pipeline passa em clone limpo; regressao do processo, bash -n, py_compile do verificador e git diff --check passam.

## Acceptance

container_profile: `bootstrap-readonly-v1`
accept: `./.board/bin/oci-run --profile bootstrap-readonly-v1 --card AUR-508`

O aceite executa assercoes reais do contrato acima; exit 0 sem cenario executado
nao e sucesso. Antes do builder, confirmar closure de leitura, runtime e paths.
Card publicador de runtime: aceite bootstrap prova o contrato de dados/loader; a regressao host .board/tests/go-profile-regression.sh coordena Git no host e o aceite Go em OCI, sem Docker aninhado. Ambas as execucoes sao obrigatorias antes de done. Preservar o owner historico AUR-403 e atualizar hashes de schema no registry.

## Skeptical mutations

- MUT-001: Retirar a capacidade de executar o teste ou adulterar o lock causa falha no mesmo gate.

## Compatibility and rollback

Preservar contratos nao alterados pelo Outcome. Documentar mudanca publica no
artefato possuido pelo card; reversao limitada a paths e sem apagar dados do usuario.
Credenciais e respostas brutas de providers nao entram na evidencia.
