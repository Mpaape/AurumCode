## Outcome

Quando o modelo devolve uma resposta que o parser nao valida
(`validation_failed`), a review NAO derruba o comando sem publicar nada: ela
publica os passes deterministicos (analise estatica + seguranca), marca o
modelo como inconclusivo com uma limitacao declarada, e o exit segue o gate
deterministico. E a regra que o AUR-458 fixou para falha de runtime de provider,
estendida a saida invalida.

## Achado medido (2026-09-15)

No auto-review do repo (PR #37, modelo `gpt-4o-mini`), o comando saiu com
`aurumcode review: could not understand the model's response (validation_failed)`
e exit 1, sem publicar achado deterministico algum. Para um gate de CI isso e
ruido: um modelo fraco ou uma resposta fora do formato derruba a PR inteira em
vez de degradar.

## Non-goals

Nao trocar o modelo; nao reimplementar o parser; nao aceitar saida malformada
como se fosse valida (nada de fabricar achado).
