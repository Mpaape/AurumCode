## Outcome

A Action Docker direta exige review por modelo com o mesmo criterio do workflow
reutilizavel. Uma execucao inconclusiva preserva o diagnostico/publicacao do CLI
e termina com falha, inclusive com analise deterministica habilitada.

## Non-goals

Alterar o comportamento opt-in do CLI local, exigir novos secrets, alterar
permissoes, refazer o parser/modelo, criar tag ou mexer no workflow reutilizavel.

## Acceptance scenarios

- AC-001: executar o entrypoint real no modo `action`, com evento de PR e
  um CLI de contrato que simula review inconclusivo, recebe
  `--exigir-qualidade` e retorna a falha do CLI ao Actions.
- AC-002: o mesmo entrypoint preserva exit 0 para review concluido e exit 3
  para achados bloqueantes; publicacao, inline, modelo e changelog continuam
  sendo repassados sem mudar seus defaults.
- AC-003: uso direto da imagem sem o sentinel `action` preserva exatamente
  os argumentos e o exit code do CLI, inclusive modo deterministico local.

## Public contract

A Action de code review passa a falhar quando o modelo nao revisou. A CLI
mantem a opcao de analise local deterministica. Inputs existentes permanecem.

## Acceptance

container_profile: `bootstrap-readonly-v1`
accept: `./.board/bin/oci-run --profile bootstrap-readonly-v1 --card AUR-507`

O aceite executa `scripts/action-entrypoint.sh` com adaptadores de contrato
isolados em um diretorio temporario para CLI e leitura do evento; verifica
argumentos, diagnostico e exit real. O teste prova a integracao do wrapper,
nao afirma ter chamado um modelo ou o GitHub. Selectors desconhecidos retornam 64.

## Skeptical mutations

- MUT-001: retirar `--exigir-qualidade` da invocacao da Action faz AC-001 falhar.
- MUT-002: substituir o exit propagado por zero faz AC-001/AC-002 falhar.

## Compatibility and rollback

Quem quer somente analise deterministica usa a CLI explicitamente, conforme
documentacao atual. Reverter os arquivos de `paths` restaura o wrapper anterior.
Nao publicar segredos ou alterar o codigo do repositorio consumidor.

## Review

  o Aurum no CI pode cumprir esse papel. Um unico parecer por candidato.
