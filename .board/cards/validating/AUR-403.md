## Outcome

o profile go-unit-offline-v1 fixa imagem Go por digest, module cache somente leitura, GONOSUMDB/GOPROXY offline, limites e comando allowlisted para testes Go sem rede.

## Non-goals

- Executar `go test` de fato ou provar que o module cache pinado cobre `go.sum`; `go-unit-offline-v1.json` apenas declara imagem, cache read-only, GOPROXY offline e comando allowlisted.
- Agregar outro profile ou aceitar fallback para profile, lock ou imagem não registrados.

## Preconditions

- O schema bootstrap de AUR-006 e o registry extensível de AUR-402 estão aprovados; os inputs do registry continuam dados não confiáveis.
- O acceptance está selado e nenhuma credential ou valor de ambiente integra as fixtures.

## Postconditions

- o profile go-unit-offline-v1 fixa imagem Go por digest, module cache somente leitura, GONOSUMDB/GOPROXY offline, limites e comando allowlisted para testes Go sem rede.
- Nenhum engine é invocado para profile inválido e nenhum byte fora de `paths` muda.
