# assistente

Assistente de terminal que manda uma pergunta a um serviço compatível com a
API da OpenAI e imprime a resposta. Boilerplate gerado com ajuda de um agente
de IA; serve de ponto de partida para "criar algo com IA".

```sh
export ASSISTENTE_API_KEY=...        # nunca no código
export ASSISTENTE_BASE_URL=https://api.openai.com/v1   # opcional
python3 assistente.py "Resuma o que é um gate de conformidade"
```
